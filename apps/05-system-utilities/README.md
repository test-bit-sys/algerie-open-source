### 🎯 Overview
Compact, single-purpose utilities solving everyday administrative and financial bottlenecks for Algerian citizens and business operators.

---

### 📋 Planned Projects & Specifications

| Program ID | Algerian Target Application | Key Features |
| :--- | :--- | :--- |
| **`dz-ccp-tool`** | **DZ-Baridi Slip Generator** | Generates and prints official postal money order slips (Chèque postal, Mandat CCP, Bordereau de versement) with automated Tafqit in Arabic/French. |
| **`dz-idara-forms`** | **DZ-Idara (الاستمارات الإدارية)** | Pre-filled printable models for: Certificats de résidence, Déclarations sur l'honneur, Procurations (وكالة), Contrats types. |
| **`dz-postal-dir`** | **DZ-Codepostal (دليل الرموز البريدية)** | Instant offline lookup of postal codes across all 1541 communes and 58 wilayas. |
