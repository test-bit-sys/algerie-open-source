# DZ-PDF Suite — The Algerian Open-Source Adobe Acrobat Alternative
## استوديو وثائق PDF الجزائري المفتوح المصدر

[العربية](README.md) • [English](README.en.md) • [Français](README.fr.md)

---

### 1. نظرة عامة (Overview)
**DZ-PDF Suite** هي حزمة أدوات تحرير، تنظيم، دمج، وتوقيع ملفات PDF بنسبة 100% دون اتصال بالإنترنت (Offline-First)، وبدون أي خوادم سحابية خارجية لحماية خصوصية الوثائق الإدارية والمالية الجزائرية.

تم بناء الحزمة بالكامل وفق معايير مشروع **[HeyPuter/everything](https://github.com/HeyPuter/everything)** بالاعتماد الحصري على JavaScript الصافي (Modern ES Modules) وواجهات HTML5 Canvas المدمجة بالمتصفح، وبدون أي مكتبات أو أطر عمل ضخمة.

---

### 2. أبرز الخصائص والقدرات

#### أ. محرك تجميع ملفات PDF مستقل (Zero-Dependency PDF Engine)
* إنشاء وبناء وثائق PDF متوافقة مع معايير PDF-1.5/1.7 مباشرة داخل المتصفح عبر `Uint8Array`.
* تحويل فوري للصور الممسوحة ضوئياً (Scanned Documents) والوثائق الرسمية إلى ملف PDF واحد متعدد الصفحات مع مقاسات قياسية (A4 عمودي وأفقي).
* حساب تلقائي لجدول الإسناد الترافقي (Cross-Reference Table `xref`) وترتيب الكائنات الداخلية بدقة بايتية كاملة.

#### ب. منظم الصفحات التفاعلي (Page Organizer)
* استعراض مصغرات الصفحات في شبكة بصرية أنيقة.
* تدوير الصفحات بزاوية 90 درجة مع الاحتفاظ بالاتجاه.
* إعادة ترتيب الصفحات بضغطة زر (تقديم / تأخير).
* تكرار وحذف الصفحات غير المرغوبة.

#### ج. الأختام والمصادقات الإدارية الجزائرية (Official Algerian Administrative Stamps)
* أختام إدارية جاهزة طبقاً للمواصفات الرسمية الجزائرية للوثائق والملفات:
  - **نسخة طبق الأصل (Conforme à l'original):** إطار أخضر زمردي معتمد للمصادقة على الوثائق.
  - **سري للغاية (Strictement Confidentiel):** للملفات والتقارير الحساسة.
  - **مدفوع بالكامل (Payé Intégralement):** للفواتير والوصولات التجارية.
  - **ملغى و لاغٍ (Annulé et Non Avenu):** للعقود والاتفاقيات الملغاة.
  - **تمت المصادقة والموافقة (Approuvé et Validé).**
* علامة مائية مخصصة (Custom Watermark) مع زاوية ميلان 45 درجة وشفافية متدرجة.

#### د. منصة التوقيع الرقمي الموجه (Vector Digital Signature Pad)
* لوحة رسم توقيع ناعمة بتقنية المنحنيات التوفيقية (Bezier Smoothing).
* ألوان الحبر الرسمي (الأزرق الإداري، الأسود، والأخضر).
* دمج بيانات الموقّع الرسمية: الاسم الكامل، الصفة/المنصب، والمكان والتاريخ (مثال: `Alger, le DD/MM/YYYY`).
* إسقاط التوقيع مباشرة بدقة عالية على أي صفحة محددة.

### 3. التشغيل والتطوير (Running & Building)

#### التشغيل المستقل عبر خادم Node المدمج (صفر تثبيت):
```bash
node apps/office-suite/dz-pdf/server.js
# يعمل فوراً على: http://localhost:3004
```

#### التطوير عبر Vite:
```bash
npm run dev:pdf
```
