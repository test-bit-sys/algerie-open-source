### 🎯 Overview
Digital tools customized for primary, middle, and high schools (C.E.M / Lycée) as well as universities in Algeria, focusing on grading, schedules, and student management.

---

### 📋 Planned Projects & Specifications

| Program ID | Algerian Target Application | Proprietary Alternative Replaced | Key Features |
| :--- | :--- | :--- | :--- |
| **`dz-school`** | **DZ-School (تسيير المؤسسات التربوية)** | Clunky Excel sheets, legacy access DBs | Algerian educational grading system (Moyennes trimestrielles, coefficients, bulletins scolaires, bulletins de notes imprimables). |
| **`dz-schedule`** | **DZ-Emploi (التوزيع الزمني الذكي)** | FET, manual chalkboard schedules | Automated constraint-based algorithm for classroom and teacher timetable generation, eliminating scheduling clashes. |
| **`dz-thesis`** | **DZ-Thesis (قوالب مذكرات التخرج)** | Manual Word formatting | Pre-configured LaTeX and Markdown templates complying with Algerian university thesis guidelines (PFE Master, Licence, Doctorat). |
