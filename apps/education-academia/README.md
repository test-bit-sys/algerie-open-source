# Education & Academia (برامج التعليم والجامعات)
## DZ Education — Schools, Universities & Academic Tools Track

[English](README.md) • [العربية](../../README.ar.md) • [Français](../../README.fr.md)

---

### Mission
Digitalize and streamline administrative and pedagogical workflows in Algerian schools (Primaire, C.E.M, Lycée) and universities with free, modern, and locally standardized software.

---

### Planned Project Blueprints

| Project Identifier | Target Application | Key Algerian Features |
| :--- | :--- | :--- |
| **`dz-school`** | **DZ-School (تسيير المؤسسات التربوية)** | Term averages calculation according to Algerian Ministry of National Education coefficients, automated printable report cards (Bulletins trimestriels). |
| **`dz-schedule`** | **DZ-Emploi (التوزيع الزمني الذكي)** | Constraint-based timetable generator resolving teacher, classroom, and lab availability without timetable clashes. |
| **`dz-thesis`** | **DZ-Thesis (قوالب مذكرات التخرج)** | Ready-to-use LaTeX, Typst, and Markdown templates matching Algerian university PFE guidelines (Licence, Master, Doctorat). |
| **`dz-biblio`** | **DZ-Biblio (تسيير المكتبات الجامعية)** | Library inventory and book lending tracking system for faculty and university department libraries. |
