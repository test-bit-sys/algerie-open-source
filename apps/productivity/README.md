# Productivity & Daily Utilities (برامج الإنتاجية والأدوات اليومية)
## DZ Productivity — Daily Workflow & Citizen Utilities Track

[English](README.md) • [العربية](../../README.ar.md) • [Français](../../README.fr.md)

---

### Mission
Provide lightweight utilities that eliminate repetitive manual workflows, streamline daily administrative requirements, and boost productivity for Algerian professionals and citizens.

---

### Active & Planned Applications

| Project Identifier | Status | Target Application | Key Features |
| :--- | :--- | :--- | :--- |
| [**`dz-disk-tree`**](dz-disk-tree/) | **Production Ready** | **DZ-DiskTree (محلل مساحات الأقراص)** | Open-source WizTree alternative: Squarified Treemap, NTFS cluster analysis, file types breakdown, top largest files, 100% offline. |
| **`dz-archive`** | **In Roadmap** | **DZ-Archive (أداة الأرشفة والضغط)** | Open-source WinRAR / 7-Zip alternative: multi-format extraction and compression (ZIP, RAR, 7Z, TAR), encrypted volumes. |
| **`dz-player`** | **In Roadmap** | **DZ-Player (مشغل الوسائط المتعددة)** | Open-source VLC alternative: lightweight offline video/audio player with Arabic subtitle encoding and audio boost. |
| **`dz-pdf`** | **In Roadmap** | **DZ-PDF (محرر ومدمج وثائق PDF)** | Offline PDF toolkit: merge, split, compress, watermark, form-fill, and OCR text extraction. |
| **`dz-idara-kit`** | **Planned** | **DZ-Citizen Kit (حقيبة المواطن الإدارية)** | Pre-filled printable models for administrative procedures (Certificats de résidence, Déclarations sur l'honneur, Procurations, Contrats types). |
| **`dz-notes`** | **Planned** | **DZ-Notes (المفكرة السريعة)** | Markdown-based distraction-free note-taking application with local encrypted storage and bi-directional RTL support. |
| **`dz-launcher`** | **Planned** | **DZ-Spotlight (البحث والوصول السريع)** | Desktop launcher utility for Windows/Linux: instant math calculations, currency conversions (EUR/USD to DZD parallel & official rates), postal code lookup. |
| **`dz-calendar`** | **Planned** | **DZ-Taqweem (التقويم المزدوج)** | Unified Gregorian and Hijri calendar with Algerian national holidays, religious dates, and academic trimester schedules. |
