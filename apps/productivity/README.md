# ⚡ Productivity & Daily Utilities (برامج الإنتاجية والأدوات اليومية)
## DZ Productivity — Daily Workflow & Citizen Utilities Track

[English](README.md) • [العربية](../../README.ar.md) • [Français](../../README.fr.md)

---

### 🌟 Mission
Provide lightweight utilities that eliminate repetitive manual workflows, streamline daily administrative requirements, and boost productivity for Algerian professionals and citizens.

---

### 📋 Planned Project Blueprints

| Project Identifier | Target Application | Key Algerian Features |
| :--- | :--- | :--- |
| **`dz-idara-kit`** | **DZ-Citizen Kit (حقيبة المواطن الإدارية)** | Pre-filled printable models for administrative procedures (Certificats de résidence, Déclarations sur l'honneur, Procurations, Contrats types). |
| **`dz-notes`** | **DZ-Notes (المفكرة السريعة)** | Markdown-based distraction-free note-taking application with local encrypted storage and bi-directional RTL support. |
| **`dz-launcher`** | **DZ-Spotlight (البحث والوصول السريع)** | Desktop launcher utility for Windows/Linux: instant math calculations, currency conversions (EUR/USD to DZD parallel & official rates), postal code lookup. |
| **`dz-calendar`** | **DZ-Taqweem (التقويم المزدوج)** | Unified Gregorian and Hijri calendar with Algerian national holidays, religious dates, and academic trimester schedules. |
