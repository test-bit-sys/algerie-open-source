# 📐 Engineering & Technical Design (برامج الهندسة والتصميم الفني)
## DZ Engineering — CAD, Structural & Technical Computing Track

[English](README.md) • [العربية](../../README.ar.md) • [Français](../../README.fr.md)

---

### 🌟 Mission
Provide Algerian civil engineers, architects, technicians, and engineering students (École Polytechnique, USTHB, USTO, etc.) with open-source tools tailored for Algerian construction norms (CGS, DTR, RPA - Règles Parasismiques Algériennes).

---

### 📋 Planned Project Blueprints

| Project Identifier | Target Application | Proprietary Equivalent | Algerian Norms & Key Features |
| :--- | :--- | :--- | :--- |
| **`dz-cad`** | **DZ-CAD (الرسم الهندسي المعماري)** | AutoCAD, ArchiCAD | 2D/3D DWG/DXF viewing and lightweight drafting with architectural layers and dimensioning. |
| **`dz-rpa`** | **DZ-RPA Calculator (الحسابات الزلزالية)** | Robot Structural, ETABS plugins | Automated calculation of seismic forces and soil coefficient parameters according to Algerian Earthquake Code (RPA 99 / Version 2003). |
| **`dz-beton`** | **DZ-Béton Armé (الخرسانة المسلحة)** | Specialized French/US calculators | Reinforced concrete beam, column, and foundation dimensioning according to Algerian Technical Regulations (DTR B.C. 2.41 / CBA 93). |
| **`dz-gis`** | **DZ-Topographie & GIS (نظم المعلومات الجغرافية)** | ArcGIS, QGIS plugins | Pre-packaged layers for Algerian administrative boundaries, road networks, Wilaya borders, and topographic coordinates. |
