# Creative Tools (برامج التصميم والوسائط الإبداعية)
## DZ Creative — Graphic Design, Vector & Audio Production Track

[English](README.md) • [العربية](../../README.ar.md) • [Français](../../README.fr.md)

---

### Mission
Provide Algerian digital artists, UI/UX designers, print shop operators, and graphic designers with full-featured creative suites tailored for commercial print standards and digital media.

---

### Planned Project Blueprints

| Project Identifier | Target Application | Proprietary Equivalent | Algerian Specifics & Key Features |
| :--- | :--- | :--- | :--- |
| **`dz-photo`** | **DZ-Design Photo (تعديل الصور والتصميم)** | Adobe Photoshop, Canva | Raster photo editor with layer masks, filters, color adjustment, and pre-set dimensions for Algerian social media campaigns and commercial signage. |
| **`dz-vector`** | **DZ-Vector (الرسم المتجه والشعارات)** | Adobe Illustrator, CorelDRAW | Vector illustration and typography editor with native support for intricate Arabic calligraphy (Thuluth, Kufic, Ruq'ah) and Tifinagh fonts. |
| **`dz-audio`** | **DZ-Audio Studio (هندسة الصوتيات)** | Adobe Audition, FL Studio | Multi-track audio recording, noise filtering, vocal leveling, podcast production, and radio ad mastering. |
| **`dz-print`** | **DZ-Print Studio (المطابع واللافتات)** | Roland VersaWorks, Corel | Pre-flight color verification (CMYK / Pantone), knife-cutting plotter drivers, large-format banner layout tools for Algerian print shops. |
