# DZ-Photo Pro — استوديو التصميم وتعديل الصور الجزائري
## Sovereign Algerian Photo Editing & Graphic Design Studio

100% Offline-First, Zero-Dependency, Native Desktop Photo & Graphic Design Studio. An open-source sovereign alternative to Adobe Photoshop, Canva, and Photopea.

---

### المميزات الرئيسية (Key Features)

1. **نظام الطبقات الاحترافي (Multi-Layer Stack Engine):**
   - إضافة وحذف وتكرار وترتيب الطبقات لأعلى وأسفل.
   - التحكم في شفافية كل طبقة على حدة (`Opacity Control`).
   - إخفاء وإظهار الطبقات الفردية وتصيير حي فائق السرعة (`Composite Rendering`).

2. **أدوات الرسم والتصميم المتكاملة (Creative Toolset):**
   - فرشاة رسم ناعمة مع تحكم ديناميكي بالحجم واللون.
   - ممحاة ذكية تعتمد على `destination-out`.
   - دلو الطلاء للتعبئة السريعة (`Paint Bucket`).
   - أداة كتابة النصوص بخطوط عربية أصيلة مع دعم كامل للـ RTL.
   - قطارة الألوان المباشرة من لوحة العمل (`Eyedropper`).

3. **مرشحات وتأثيرات بصرية جزائرية وعالمية (Filters & Transformations):**
   - تحويل أبيض وأسود (`Grayscale`).
   - سيبيا عتيق (`Vintage Sepia`).
   - عكس الألوان (`Color Inversion`).
   - مرشح غروب الصحراء الجزائرية الدافئ (`Algerian Sahara Warm Sunset`).
   - مرشح زرقة البحر الأبيض المتوسط (`Mediterranean Cool Blue`).
   - انعكاس أفقي وعمودي فوري (`Flip H / Flip V`).

4. **قوالب الأبعاد القياسية (Algerian & Social Media Presets):**
   - منشورات انستغرام وفيسبوك (1080x1080).
   - ريلز وستوري عمودي (1080x1920).
   - غلاف يوتيوب وفيديو عالي الدقة (1920x1080).
   - غلاف وبانر الوسائط الاجتماعية (1200x630).
   - قياسات مخصصة لأي أبعاد يحددها المصمم.

5. **تنسيق المشاريع السيادي (.dzphoto):**
   - حفظ واسترجاع بنية الطبقات بالكامل بدون فقدان الجودة.
   - استيراد الصور بالسحب والإفلات (`Drag & Drop`).
   - تصدير فائق الدقة بصيغ `PNG`, `JPEG`, `WEBP`.

---

### التشغيل (Running Locally)

```bash
# تشغيل خادم استوديو الصور (المنفذ 3010)
npm run start:photo
```
أو عبر التوجه مباشرة إلى: `http://localhost:3010`
