# 🚀 تطبيق `DZ-Idara` (مستقبلي - المرحلة 3)
## Algerian Administrative Documents & Forms Generator

### 📋 النماذج المستهدفة
* شهادات العمل والتربص (Attestation de travail / stage).
* نماذج الوكالات والتنازلات القانونية والتصاريح الشرفية.
* استمارات الحالة المدنية والطلبات الإدارية الموجهة للبلديات والدوائر والوزارات.
* استمارات السحب والدفع البريدي (CCP / Baridimob slips).
