# DZ-Player — The Algerian Open-Source VLC Alternative
## مشغل الوسائط المتعددة الجزائري المفتوح المصدر

[العربية](README.md) • [English](README.en.md) • [Français](README.fr.md)

### 1. نظرة عامة (Overview)
**DZ-Player** هو مشغل وسائط متعددة عالي الأداء، مفتوح المصدر بنسبة 100% وخالٍ من أي تعقب أو اتصال خارجي (Offline-First). صُمم وبُني وفق معايير مشروع **[HeyPuter/everything](https://github.com/HeyPuter/everything)** بالاعتماد الحصري على JavaScript الصافي (Modern ES Modules) وواجهات المتصفح الحديثة (Web Audio API, Canvas, Fullscreen API) دون أي مكتبات ثقيلة أو اعتمادات خارجية.

تم استلهام البنية الهندسية للبرنامج من خلال التحليل العكسي (Reverse Engineering) لبرنامج **VLC Media Player** (`vlc.exe`، `libvlccore.dll`، ومرشحات `audio_filter` و`video_filter`)، مع تقديم حلول مبتكرة لمشاكل واجهت المستخدمين الجزائريين والعرب لعقود.

### 2. أبرز الخصائص والابتكارات

#### أ. محرك حل معضلة ترميز الترجمة العربية (Arabic Subtitle Auto-Detection)
* **المشكلة التاريخية:** يعاني مستخدمو مشغلات الوسائط (بما فيها VLC) في العالم العربي من ظهور ملفات الترجمة العربية القديمة ذات ترميز `Windows-1256` كرموز مشوهة وغير مقروءة (`ãÑÍÈÇ Èßã` أو `Ø§Ù„Ø¹Ø±Ø¨ÙŠØ©`) عند محاولة قراءتها بترميز `UTF-8`.
* **الحل في DZ-Player:** محرك فحص إحصائي وتحليلي ذكي يتعرف تلقائياً على بايتات الحروف العربية بترميز `Windows-1256 / CP-1256` أو `UTF-8` ويقوم بفك تشفيرها وإظهارها فوراً بخط عربي واضح مع محاذاة تلقائية لليمين (RTL).
* **مزامنة زمنية فورية:** تعديل تأخير أو تقديم الترجمة بضغطة زر أو باختصارات لوحة المفاتيح (`G` لتأخير 50 ملي ثانية، `H` لتقديم 50 ملي ثانية).

#### ب. المعادل الصوتي المتقدم والتضخيم الفائق (10-Band EQ & 300% Audio Boost)
* محاكاة دقيقة لمعادل VLC ذو العشرة ترددات المعيارية:
  `60Hz`, `170Hz`, `310Hz`, `600Hz`, `1kHz`, `3kHz`, `6kHz`, `12kHz`, `14kHz`, `16kHz`.
* 16 إعداداً مسبقاً (Presets): Rock, Pop, Classical, Full Bass, Full Treble, Vocal/Speech, Party, Reggae, Techno, etc.
* **تضخيم الصوت حتى 300%:** ميزة VLC الشهيرة لتضخيم المقاطع ذات الصوت المنخفض عبر عقدة `GainNode` في Web Audio API.
* **محلل الطيف الترددي الحي (Spectrum Visualizer):** رسم بياني فوري لترددات الصوت أثناء التشغيل.

#### ج. مرشحات الفيديو والتحكم الهندسي (Video Effects & Aspect Ratio)
* تعديل السطوع (Brightness)، التباين (Contrast)، التشبع (Saturation)، ودرجة اللون (Hue Rotate) بتسريع عتادي (GPU-accelerated).
* نسب الأبعاد المتعددة: `16:9` عريض، `4:3` قياسي، `1:1` مربع، `21:9` سينمائي، و`Cover` ملء الشاشة.
* التدوير بزاوية 90 درجة والانعكاس الأفقي (Mirror Mode).
* **التقاط لقطة شاشة نقية (Frame Snapshot):** حفظ الإطار المعروض بدقته الأصلية بضغطة واحدة (`Shift + S`).

#### د. قائمة تشغيل متقدمة (Playlist Engine)
* السحب والإفلات لمقاطع متعددة.
* أوضاع التكرار (Repeat All, Repeat One, Shuffle).

### 3. اختصارات لوحة المفاتيح المعيارية (Keyboard Shortcuts)

| المفتاح | الوظيفة |
| :--- | :--- |
| `Space` | تشغيل / إيقاف مؤقت (Play / Pause) |
| `F` | ملء الشاشة (Toggle Fullscreen) |
| `M` | كتم / تفعيل الصوت (Mute) |
| `السهم للأعلى / للأسفل` | رفع / خفض الصوت بمقدار 5% (Volume +/- 5%) |
| `السهم لليمين / لليسار` | تقديم / ترجيع 5 ثوانٍ |
| `Ctrl + يمين / يسار` | تقديم / ترجيع دقيقة كاملة (60 ثانية) |
| `[` / `]` | تقليل / زيادة سرعة التشغيل بمقدار 0.1x |
| `=` | إعادة ضبط سرعة التشغيل إلى 1.0x |
| `E` | التقدم إطاراً واحداً للأمام (Frame-by-Frame Step) |
| `G` / `H` | تأخير / تقديم مزامنة الترجمة بمقدار 50 ملي ثانية |
| `Shift + S` | التقاط صورة للإطار الحالي بدقته الأصلية |
| `S` | إيقاف التشغيل والعودة للبداية |

### 4. التشغيل والتطوير (Running & Building)

#### التشغيل المستقل عبر خادم Node المدمج (صفر تثبيت):
```bash
node apps/multimedia/dz-player/server.js
# يعمل فوراً على: http://localhost:3003
```

#### التطوير عبر Vite:
```bash
npm run dev:player
```
