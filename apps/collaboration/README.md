# Collaboration & Teamwork (برامج التواصل والعمل الجماعي)
## DZ Collab — Team Messaging, Task Boards & Communication Track

[English](README.md) • [العربية](../../README.ar.md) • [Français](../../README.fr.md)

---

### Mission
Enable Algerian universities, tech communities, startup teams, and companies to collaborate effectively with self-hostable, low-bandwidth-friendly communication and project management tools.

---

### Planned Project Blueprints

| Project Identifier | Target Application | Proprietary Equivalent | Status & Key Features |
| :--- | :--- | :--- | :--- |
| [**`dz-boards`**](./dz-boards/) | [**DZ-Boards Pro (إدارة المهام والمشاريع)**](./dz-boards/) | Trello, Jira, Focalboard | **Active (Port 3011)** — Drag & drop Kanban boards, Algerian graduation (PFE) & startup launch templates, checklists, analytics, JSON/CSV export. |
| **`dz-teams`** | **DZ-Chat & Workspaces** | Slack, Microsoft Teams, Discord | Self-hostable team chat with channels, voice rooms, file sharing, and optimized low-bandwidth mode for Algerian mobile connections. |
| **`dz-meet`** | **DZ-Conference (الاجتماعات المرئية)** | Zoom, Google Meet | Ultra-lightweight WebRTC video meetings that do not require software installation, featuring screen sharing and virtual whiteboard. |
| **`dz-wiki`** | **DZ-Knowledge (قواعد المعرفة للفرق)** | Notion, Confluence | Fast internal documentation and team wiki engine for Algerian research labs, student clubs, and tech startups. |
