# DZ-Boards Pro — لوحات وإدارة مهام المشاريع السيادية
## Sovereign Algerian Kanban & Agile Project Management Platform

100% Offline-First, Zero-Dependency, Native Desktop & Browser Kanban Suite. An open-source sovereign alternative to Trello, Jira, and Focalboard.

---

### المميزات الرئيسية (Key Features)

1. **لوحات كانبان تفاعلية بالسحب والإفلات (Interactive Drag & Drop):**
   - نقل سلس للمهام بين الأعمدة مع مؤشرات بصرية لمكان الإفلات.
   - إضافة وحذف وتعديل الأعمدة بحرية تامة مع تخصيص الألوان.
   - بطاقات مهام غنية مع درجات الأولوية (عاجل جداً، أولوية عالية، متوسطة، منخفضة).

2. **نماذج مشاريع وطنية جاهزة (Official Algerian Project Templates):**
   - **مشروع التخرج الجامعي ومذكرة الليسانس/الماستر (PFE Master & License):** خطة عمل أكاديمية للمؤطر، جمع الدراسات السابقة، نمذجة UML، كتابة المذكرة، وتجهيز العرض النهائي.
   - **إطلاق شركة ناشئة ومتجر إلكتروني جزائري (DZ E-Commerce Startup):** استخراج السجل التجاري (Code 607001 CNRC)، الانتساب الجبائي (NIF/NIS)، تكامل بوابة الدفع (SATIM / CIB / الذهبية)، والتعاقد مع شركات الشحن عبر 58 ولاية.
   - **دورة تطوير برمجية رشيقة (Agile 2-Week Sprint):** إدارة سبرنت البرمجة، مراجعة الكود، واختبارات الجودة.

3. **قوائم تحقق وتتبع الإنجاز (Checklists & Progress Tracking):**
   - دعم القوائم الفرعية لكل مهمة وتحديث شريط الإنجاز تلقائياً.
   - شريط مؤشرات علوي يوضح إجمالي المهام، قيد التنفيذ، العاجل، والمكتمل مع نسبة الإنجاز المئوية.

4. **بحث وفلترة فورية (Instant Search & Priority Filtering):**
   - بحث لحظي في العناوين والشروحات والوسوم (Tags).
   - فلترة حسب درجات الأولوية بضغطة زر.

5. **تصدير واستيراد سيادي (Data Sovereignty):**
   - حفظ تلقائي مستمر في التخزين المحلي (`localStorage`).
   - تصدير واستيراد بنية اللوحة كاملة بصيغة `.dzboard` (JSON).
   - تصدير جدول المهام بصيغة `CSV` للتقارير وجداول البيانات.

---

### التشغيل (Running Locally)

```bash
# تشغيل خادم لوحات كانبان (المنفذ 3011)
npm run start:boards
```
أو عبر التوجه مباشرة إلى: `http://localhost:3011`
