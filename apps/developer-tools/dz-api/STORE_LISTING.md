# API Client

**Build, send and test HTTP and WebSocket requests**

## Short description

Build and send HTTP requests, write tests, organize collections and switch environments. Works in your browser, syncs with your Puter cloud.

## Long description

API Client is a workbench for the APIs you build and use. Pick a method, type a URL and send. Query parameters stay in step with the URL, headers come with suggestions, and bodies can be JSON, XML, text, form fields, files or GraphQL, edited in a code editor with highlighting.

Responses show their status, time and size, with a breakdown of where the time went. Read the body pretty-printed, raw or as a preview, filter JSON with a path, and look through headers, cookies and test results.

Keep requests in collections and folders, and switch between environments such as development and production with a click. Use {{variables}} anywhere: the app highlights them, suggests them as you type and shows their values on hover.

Write tests and pre-request scripts in JavaScript, then run a whole collection, many times over and with rows from a CSV or JSON file. Scripts run in an isolated sandbox.

Import collection v2 files, OpenAPI, HAR, Insomnia exports and cURL commands, and copy any request as code in 17 languages.

Requests go straight from your browser, or through the Puter relay when a server does not allow requests from web pages. Signed in, your workspace syncs across devices and you can share collections with other Puter users.

API Client works on a laptop, tablet or phone, follows your light or dark setting and is built to be usable with a keyboard and a screen reader.

## Key features

- Request builder with params, headers, auth (bearer, basic, API key, OAuth 2.0, AWS Signature) and every common body type.
- Response viewer with pretty, raw and preview modes, JSON filtering, timing and size details.
- Collections, folders, environments, globals and history.
- Pre-request and test scripts, plus a collection runner with data files.
- WebSocket requests with a message log.
- Import and export, cURL paste and code snippets in 17 languages.
- Cloud sync and sharing with your Puter account.
- System, light and dark themes.
