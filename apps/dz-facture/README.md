# 🚀 `DZ-Facture` Studio
## Flagship Invoicing, Inventory & POS Application

An open-source desktop and local web invoicing studio tailored for merchants, pharmacies, SMEs, and commercial offices in Algeria.

---

### ✨ Features
* **Trilingual Interface:** Instant switching between **Arabic (RTL)**, **French (LTR)**, and **English (LTR)**.
* **100% Algerian Compliance:** Automatic VAT rates (19% & 9%), cash payment fiscal stamp (Timbre fiscal 1%), and standard mentions (NIF, NIS, RC, AI, RIB).
* **Live Tafqit:** Real-time number-to-words currency conversion displayed dynamically as you type.
* **A4 Print Engine:** Formatted to print or export as PDF according to Algerian Executive Decree 05-468.
* **Local-First & Offline:** Zero internet required. Runs directly on your machine.

---

### 💻 Running the Studio Locally

```bash
# In the repository root
npm start
```
Then visit **`http://localhost:3000`** in any modern web browser.
