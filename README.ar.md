## 🌟 الرؤية والأهداف

**المنظومة الجزائرية للبرمجيات المفتوحة المصدر (DZ Open Suite)** هي مبادرة وطنية تهدف لبناء بدائل برمجية عصرية، مجانية 100%، وآمنة للاستغناء عن البرمجيات الاحتكارية أو المقرصنة المستخدمة بكثرة في الشركات، المدارس، استوديوهات المونتاج، والإدارات العمومية الجزائرية.

تم تصميم المنظومة من الصفر لتراعي **الخصوصية القانونية، الجبائية واللغوية الجزائرية**، تعزيزاً للسيادة الرقمية ودعماً للمطورين والمصممين والطلبة الجزائريين.

---

## 🗺️ مسارات وتصنيفات البرمجيات (Software Tracks)

تم تنظيم المنظومة إلى **5 مسارات تخصصية رئيسية**:

```
algerie-open-source/
│
├── 📁 apps/
│   ├── 🏢 01-business-management/    # برمجيات الإدارة، الفوترة، المحاسبة، والأجور
│   ├── 🎬 02-creative-multimedia/      # برمجيات المونتاج، تعديل الصور وهندسة الصوت
│   ├── 📝 03-office-productivity/      # حزمة برمجيات المكتب والوثائق الإدارية
│   ├── 🎓 04-education-academia/       # برمجيات التعليم، تسيير النقاط والتوزيع الزمني
│   └── 🛠️ 05-system-utilities/         # أدوات الصكوك البريدية CCP والاستمارات اليومية
│
├── 📁 packages/                        # محركات الحساب المشتركة المستقلة
│   ├── dz-tafqit/                      # مكتبة التفقيط المالي بالدينار (عربي، فرنسي، إنجليزي)
│   ├── dz-fiscal/                      # محرك الضرائب والتحقق من NIF/NIS/RC/CCP
│   ├── dz-geo/                         # قاعدة بيانات 58 ولاية والبحث الإداري
│   └── dz-ui/                          # نظام تصميم الواجهات ثنائي الاتجاه RTL/LTR
│
└── 📁 docs/                            # دراسات القوانين والمعايير والتصميم الهندسي
```

## 📊 مصفوفة البرمجيات والبدائل المقترحة

| المسار | البرنامج المقترح | البديل التجاري الشائع | المزايا والخصوصية الجزائرية |
| :--- | :--- | :--- | :--- |
| **🏢 الإدارة** | `dz-facture` | Sage / برامج الدلفي المقرصنة | فواتير A4 مطابقة للمرسوم 05-468، رسم الطابع 1%، وطابعات التذاكر الحرارية. |
| **🏢 الإدارة** | `dz-compta` | PC Compta / DLG | متوافق تماماً مع النظام المحاسبي المالي الجزائري (SCF)، ومساعد تصريح G50. |
| **🏢 الإدارة** | `dz-paie` | PC Paie | تطبيق قانون العمل وسلم IRG، واشتراكات الضمان الاجتماعي (CNAS 9% و 26%). |
| **🎬 المونتاج** | `dz-video` | Adobe Premiere / CapCut PC | مونتاج سريع وخفيف مع دعم كتابة العناوين العربية السليمة (بدون حروف مقلوبة). |
| **🎬 الوسائط** | `dz-photo` | Adobe Photoshop / Canva | تعديل الصور والتصميم مع مقاسات مسبقة للافتات والمنشورات التجارية الجزائرية. |
| **🎬 الصوت** | `dz-audio` | Adobe Audition / FL Studio | تسجيل وهندسة الصوت للبودكاست، إزالة الضوضاء وتعديل المؤثرات. |
| **📝 المكتب** | `dz-docs` | Microsoft Word | محرر نصوص ثنائي اللغة وقوالب جاهزة للمراسلات والشهادات الإدارية. |
| **📝 المكتب** | `dz-sheets` | Microsoft Excel | جداول حسابية مزودة بدوال مالية جزائرية مدمجة (`=TAFQIT_AR()`). |
| **📝 المكتب** | `dz-pdf` | Adobe Acrobat / iLovePDF | دمج وضغط وتوقيع وتعبئة ملفات واستمارات PDF دون الحاجة لرفعها للإنترنت. |
| **🎓 التعليم** | `dz-school` | برامج إكسل المعقدة | تسيير المؤسسات، حساب المعدلات الفصلية والمعاملات واستخراج كشوف النقاط. |
| **🎓 التعليم** | `dz-schedule` | FET / البرامج اليدوية | خوارزمية ذكية لتوليد جداول التوقيت للأساتذة والأقسام بدون أي تضارب. |
| **🛠️ الخدمات** | `dz-ccp-tool` | التعبئة اليدوية | طباعة آلية وفورية لصكوك بريد الجزائر وحوالات CCP مع التفقيط الآلي. |

## 📦 الحزم المشتركة المكتملة (`packages/`)

المحركات المشتركة مبنية بدون أي تبعيات خارجية ومختبرة بنسبة نجاح **100%**:

```bash
# تشغيل كافة اختبارات الوحدة عبر الحزم
npm test
```

* **`@dz-suite/tafqit`**: تفقيط المبالغ المالية إلى حروف باللغات **العربية**، **الفرنسية**، و**الإنجليزية** مع أختام الأمان القانونية.
* **`@dz-suite/fiscal`**: التحقق من صحة أرقام **NIF (15 رقماً)**، **NIS (20 رقماً)**، **RC**، ومفتاح **CCP**، وحساب TVA (19% و 9%) ورسم الطابع.
* **`@dz-suite/geo`**: قاعدة بيانات رسمية لـ **58 ولاية جزائرية** مع البحث السريع.
