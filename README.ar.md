# 🇩🇿 المنظومة الجزائرية للبرمجيات المفتوحة المصدر
## DZ Open Suite — Algerian Open Source Ecosystem

[English](README.md) • [العربية](README.ar.md) • [Français](README.fr.md)

---

> **مشروع وطني مفتوح المصدر 100%** يهدف لبناء بدائل عصرية، مجانية، وآمنة للبرمجيات المكتبية والتجارية والإدارية الأكثر استخداماً في الجزائر، مصممة خصيصاً لتناسب البيئة القانونية والتقنية الجزائرية.

---

### 🌟 دوافع المشروع
1. **الاستغناء عن البرمجيات المقرصنة:** أغلب المحلات والشركات والإدارات تستخدم برامج تجارية مقرصنة أو قديمة جداً (تعود لحقبة Delphi و Access) تفتقر للأمان والموثوقية.
2. **التوافق التام مع الخصوصية الجزائرية:**
   * الحسابات الجبائية والضرائب (TVA 9% / 19%, Timbre fiscal, IRG, IBS, TAP).
   * المعايير الإلزامية للفواتير والوثائق (NIF, NIS, RC, AI, RIB).
   * ثلاثية اللغة المتكاملة (العربية، الفرنسية، والإنجليزية) مع دعم أصيل لليمين واليسار (RTL/LTR).
   * العمل دون الحاجة للإنترنت (**Offline-First**) لحماية البيانات وسرعة العمل.
3. **تشجيع مجتمع المطورين الجزائريين:** توفير منصة كود نظيفة موثقة تسهم في تدريب وتشغيل المطورين والطلبة في مشاريع محلية حقيقية.

### 🏛️ هيكلية المنظومة (Monorepo Layout)

```
algerie-open-source/
│
├── 📁 docs/                     # التوثيق الشامل، القوانين، والمواصفات المعمارية
│   ├── standards/               # المعايير الجبائية، التقسيم الإداري، وقواعد التفقيط
│   ├── architecture/            # التصميم الهندسي وقواعد البيانات والواجهات
│   └── CONTRIBUTING.md          # دليل المساهمة للمطورين
│
├── 📁 packages/                 # المكتبات المشتركة (Shared Core)
│   ├── dz-tafqit/               # مكتبة تحويل الأرقام إلى مبالغ مكتوبة (عربي، فرنسي، إنجليزي)
│   ├── dz-geo/                  # قاعدة بيانات 58 ولاية، الدوائر، البلديات، والرموز البريدية
│   ├── dz-fiscal/               # محرك الحسابات الضريبية والتحقق من صحة NIF / NIS / RC
│   └── dz-ui/                   # مكونات الواجهة الرسومية الموحدة والمتجاوبة
│
└── 📁 apps/                     # التطبيقات المستقلة
    ├── dz-facture/              # التطبيق الرائد: إدارة الفواتير، المخزون، ونقاط البيع
    ├── dz-paie/                 # كشوف الرواتب وقانون العمل والتصريح (CNAS)
    └── dz-idara/                # محررات الوثائق والنماذج الإدارية والشهادات
```

### 🎯 التطبيق الرائد: `DZ-Facture`
تطبيق **الفواتير والمخزون ونقاط البيع** يعمل محلياً ويدعم:
* فواتير A4 مطابقة للمرسوم التنفيذي 05-468.
* حساب تلقائي لضرائب TVA ورسم الطابع (Timbre fiscal).
* تفقيط مالي فوري بالدينار الجزائري باللغات الثلاث.
* تشغيل محلي فوري عبر: `npm start`
