## الرؤية الاستراتيجية والأهداف الوطنية

**المنظومة الجزائرية للبرمجيات المفتوحة المصدر (DZ Open Suite)** هي مبادرة وطنية كبرى لتأسيس، تنظيم، وتطوير بدائل برمجية حرة ومجانية 100% للبرامج التجارية والمقرصنة الأكثر استخداماً في الإدارات العمومية، المؤسسات الاقتصادية، والمصالح المهنية الجزائرية.

### الأهداف الأساسية:
1. **القضاء على البرمجيات المقرصنة والأنظمة المتقادمة**: الاستغناء النهائي عن البرمجيات المهجورة والقديمة (Visual Basic 6, Delphi 7, Access 2003) واستبدالها بحلول عصرية مبنية بأحدث معايير الويب المفتوح والأمان الرقمي.
2. **السيادة الرقمية وسرية البيانات الوطنية**: ضمان عدم خروج المعاملات المالية، السجلات الإدارية، وعقود المواطنين إلى أي خوادم سحابية أجنبية. المعالجة محلية بالكامل ومغلقة داخل الشبكة الداخلية (**Offline-First**).
3. **التطابق الصارم مع القوانين والأنظمة الجزائرية**: تطبيق أحكام المرسوم التنفيذي 05-468 (شروط الفوترة)، القانون 18-05 (التجارة الإلكترونية)، النظام المحاسبي المالي SCF، حساب ضريبة القيمة المضافة TVA (19% و 9%)، رسم الطابع الجبائي، التفقيط بالدينار الجزائري، واستخدام الأختام الإدارية الرسمية المعتمدة.
4. **أعلى معايير هندسة البرمجيات (HeyPuter Standard)**: برمجة صافية بـ Vanilla JS ES Modules دون أي أطر عمل ثقيلة أو اعتمادات خارجية، صفر رموز تعبيرية (Zero Emojis)، والاعتماد الحصري على أيقونات المتجهات الهندسية (Vector SVGs).

### 1. برمجية الفوترة ونقاط البيع DZ-Facture & POS (المنفذ :3000)
*المسار المصدري: [`apps/business-enterprise/dz-facture/`](apps/business-enterprise/dz-facture/)*

الحل الوطني المفتوح المصدر للفوترة التجارية وإدارة المبيعات ونقاط البيع المصمم خصيصاً للمؤسسات والتجار في الجزائر:
- **تطابق قانوني كامل**: يتضمن الحقول القانونية الإلزامية: الرقم التعريفي الجبائي NIF (15 رقماً)، الرقم الإحصائي NIS (20 رقماً)، السجل التجاري RC، رقم المادة الجبائية Article d'Imposition، ورقم الحساب البنكي/البريدي RIB/CCP.
- **محرك التفقيط المالي (Tafqit)**: تحويل المبالغ المالية آلياً إلى كلمات معربة قانونية بالدينار الجزائري (مثال: *ثمانمائة وإحدى عشر ألف وسبعمائة دينار جزائري لا غير*).
- **وضع مزدوج للفوترة وصناديق الدفع (POS)**: قارئ الباركود السريع، طباعة التذاكر الحرارية (58mm / 80mm)، وإصدار فواتير المؤسسات الرسمية بمقاس A4.
- **تقرير الإغلاق اليومي Z-Report**: حساب الحصيلة اليومية ومطابقة صندوق النقدية وجرد المصاريف اليومية.

### 2. برمجية فحص وسائط التخزين DZ-Disk-Tree (المنفذ :3001)
*المسار المصدري: [`apps/productivity/dz-disk-tree/`](apps/productivity/dz-disk-tree/)*

بديل متطابق 1:1 لبرنامج **WizTree** و TreeSize لفحص الأقراص وتحليل استهلاك المساحة واستعادة السعة التخزينية الضائعة:
- **شاشة عرض مزدوجة متزامنة (Split-Window)**: جدول شجري متعدد الأعمدة في القسم العلوي وخريطة شجرية بارزة ومظللة مجسمة (**Cushioned Treemap Canvas**) في القسم السفلي مع فاصل سحب مباشر.
- **تحديد ثنائي الاتجاه**: النقر على أي مجلد في الشجرة يُكبر المخطط؛ والنقر على أي كتلة مرئية في المخطط يحدد موقعها مباشرة في الشجرة.
- **فرز الأعمدة التفاعلي**: فرز حسب الاسم، نسبة الحجم، الحجم الفعلي، الحجم المحجوز (Allocated Cluster Space)، عدد الملفات، عدد المجلدات، وتاريخ التعديل مع أسهم الترتيب.
- **تنقل كامل عبر لوحة المفاتيح**: دعم كامل لأسهم التوجيه (`ArrowUp`, `ArrowDown`, `ArrowLeft`, `ArrowRight`, `Enter`, `Backspace`).
- **تقرير تدقيق تنفيذي قابل للطباعة**: توليد تقرير رسمي HTML مدعم بلقطة مدمجة من خريطة الأقراص وجداول تفصيلية لأكبر الملفات استهلاكاً للمساحة.

### 3. برمجية إدارة وضغط الأرشيف DZ-Archive (المنفذ :3002)
*المسار المصدري: [`apps/productivity/dz-archive/`](apps/productivity/dz-archive/)*

بديل مكتبي متطابق 1:1 لبرنامج **WinRAR** و 7-Zip لإنشاء، فحص، تشفير، واستخراج الأرشيفات المضغوطة:
- **واجهة وقوائم WinRAR الأصلية**: شريط قوائم مألوف (`File`, `Commands`, `Tools`, `Options`, `Help`) وشريط الأدوات الأيقوني الكبير (`Add`, `Extract To`, `Test`, `View`, `Delete`, `Find`, `Wizard`, `Info`, `Lock`, `Comment`, `Benchmark`).
- **نافذة خيارات الأرشيف بـ 6 تبويبات**: إعدادات متكاملة تشمل تبويبات (`General`, `Advanced`, `Files`, `Backup`, `Time`, `Comment`).
- **تشفير عسكري متقدم AES-256-GCM**: حماية أمنية مشفرة بكلمة مرور عبر **Web Crypto API** مع اشتقاق المفاتيح بواسطة **PBKDF2**.
- **عارض ملفات داخلي متعدد الأنماط**: فحص المحتوى فورياً دون استخراج الملفات عبر عارض النصوص، عارض الهكسا (**Hex Dump**) بمحاذاة 16 بايت وعرض ASCII، وعارض الوسائط والصور.
- **مقياس كفاءة العتاد والمعالج (Hardware Benchmark)**: فحص سرعة الضغط الآنية بالميغابايت/ثانية واحتساب نقاط تقييم الأداء استناداً إلى عدد مسارات المعالج (CPU Threads).

### 4. مشغل الوسائط المتعددة DZ-Player (المنفذ :3003)
*المسار المصدري: [`apps/multimedia/dz-player/`](apps/multimedia/dz-player/)*

بديل مكتبي 1:1 لمشغل الوسائط الشهير **VLC Media Player** مخصص لمعالجة الصوت والفيديو المتقدمة:
- **واجهة VLC الكلاسيكية**: شريط قوائم علوي كامل، نافذة عرض داكنة عالية التباين بشعار المخروط، وشريط تحكم سفلي احترافي.
- **تضخيم الصوت الفائق حتى 300%**: شريط صوت بمؤشر رقمي حقيقي يتجاوز الحدود التقليدية ليصل إلى **300%** لمعالجة المقاطع الضعيفة عبر عقدة `GainNode`.
- **نافذة المؤثرات والمرشحات الموحدة (Ctrl+E)**:
  - **معادل صوتي 10 حزم (Graphic Equalizer)**: ترددات قياسية (من 60Hz إلى 16kHz) مع قوالب جاهزة (Rock, Pop, Classical, Flat, Full Bass, Voice).
  - **ضاغط الصوت الديناميكي (Audio Compressor)**: تحكم احترافي في عتبة الصوت (Threshold)، النسبة (Ratio)، والحدة (Attack/Release).
  - **هندسة وألوان الفيديو**: تدوير الفيديو بـ 90°/180°/270°، الانعكاس الأفقي، وضبط السطوع والتباين والتشبع ودرجة اللون.
  - **تزامن الصوت والترجمة**: معالجة التأخير أو التقديم بالمللي ثانية لضمان التزامن السمعي البصري المثالي.
- **دقة التشغيل**: حلقة التكرار A-B، التقاط إطارات الفيديو كصور عالية الدقة، وتشغيل البث الشبكي الحي (HTTP/HTTPS/HLS).

### 5. استوديو معالجة وتوقيع وثائق PDF DZ-PDF Pro (المنفذ :3004)
*المسار المصدري: [`apps/office-suite/dz-pdf/`](apps/office-suite/dz-pdf/)*

بديل مكتبي 1:1 لبرنامج **Adobe Acrobat Pro** لمعاينة، تحرير، تظليل، تنظيم، وتوقيع الوثائق الرسمية:
- **شريط أدوات Acrobat المتكامل**: أداة التحديد (`V`)، أداة اليد والتحريك (`H`)، قلم الرسم الحر والتوقيع (`P`)، قلم التظليل اللوني (`U`)، إدراج نصوص وكتابة حرة (`T`)، مستطيل الحجب الأمني الأسود (**Redaction Tool** `R`)، والملاحظات اللاصقة (**Sticky Notes** `N`).
- **منظومة الأختام والمصادقات الإدارية الجزائرية الرسمية**:
  - **الختم الدائري الرسمي للجمهورية**: ختم مزدوج الحلقة للجمهورية الجزائرية الديمقراطية الشعبية (*الجمهورية الجزائرية الديمقراطية الشعبية / RÉPUBLIQUE ALGÉRIENNE DÉMOCRATIQUE ET POPULAIRE*) مع النجمة والهلال، الولاية والتاريخ.
  - **أختام إدارية جاهزة**: *نسخة طبق الأصل (Conforme à l'Original)*، *وارد ومسجل بتاريخ (Courrier Arrivé)*، *مدفوع بالكامل (Payé)*، *سري للغاية (Confidentiel)*، *تمت المصادقة (Approuvé)*، *ملغى (Annulé)*، و*عاجل جداً (Urgent)*.
- **لوحة التوقيع الرقمي المعتمد للمستندات (Fill & Sign)**: لوحة رسم توقيع ناعمة بمنحنيات Bézier، ألوان الحبر الرسمي، بطاقة مصادقة إدارية تتضمن اسم الموقّع، صفته، الولاية، التاريخ، ورمز التحقق الرقمي المعتمد.
- **وضع تنظيم وترتيب الصفحات (Organize Pages Grid)**: شبكة بصرية لفرز الصفحات بالسحب والإفلات، التدوير الفردي أو الجماعي بـ 90°، التكرار، الحذف، وإدراج صفحات بيضاء جديدة.
- **نماذج إدارية وتجارية جزائرية مدمجة**: تحميل فوري لـ **شهادة إدارية رسمية جزائرية** و**فاتورة وعقد توريد تجاري بالدينار الجزائري (DZD)** بكافة الضرائب والتفقيط لتجربة النظام مباشرة.

## الركائز الهندسية (معيار HeyPuter الصارم)

تلتزم كافة برمجيات المنظومة بالمعايير الهندسية لمشروع **HeyPuter / everything**:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        DZ Open Suite Monorepo                          │
├────────────────────────────────────────────────────────────────────────┤
│  الطبقة 1: تقنيات الويب الأصلية (HTML5 Canvas 2D · Web Audio · Web Crypto)│
│  الطبقة 2: وحدات جافاسكربت المعيارية الصافية (Vanilla ES Modules)        │
│  الطبقة 3: قواعد البيانات المحلية (100% Offline-First)                  │
│  الطبقة 4: نظام تصميم ثنائي الاتجاه (العربية من اليمين لليسار RTL)       │
│  الطبقة 5: هندسة المتجهات النقية (أيقونات SVG خالية تماماً من الإيموجي)  │
└────────────────────────────────────────────────────────────────────────┘
```

1. **صفر أطر عمل ثقيلة (Zero Framework Bloat)**: لا وجود لـ React أو Angular أو Vue أو حزم npm الضخمة أثناء التشغيل؛ استخدام مباشر للـ DOM الأصلي ووحدات ES Modules مما يمنح التطبيقات سرعة إقلاع لحظية واستقراراً لعقود.
2. **محلي ومستقل بالكامل (Offline-First)**: استقلالية تامة عن الاتصال بالإنترنت، تعمل البرمجيات بكفاءة غير منقطعة في أقصى الظروف (المكاتب البلدية المعزولة، المستشفيات، المعابر الحدودية، والمصانع).
3. **أصالة الاتجاهية ودعم العربية**: اللغة العربية مواطن أصيل من الدرجة الأولى بالاتجاه الطبيعي من اليمين لليسار (RTL) بالتوازي مع الفرنسية والإنجليزية.
4. **الانضباط البصري الصارم**: كافة الأيقونات والعناصر الرسومية مرسومة بمتجهات SVG رياضية دقيقة؛ يُمنع منعاً باتاً استخدام الرموز التعبيرية (Emojis) في واجهات البرامج أو الكود المصدري.

## التشغيل السريع والنشر المحلي

### المتطلبات الأساسية
- تثبيت [Node.js](https://nodejs.org/) الإصدار 18.0.0 أو أحدث.
- متصفح حديث (Chrome, Edge, Firefox, Brave, Safari).

### 1. استنساخ المستودع (Clone)
```bash
git clone https://github.com/test-bit-sys/algerie-open-source.git
cd algerie-open-source
```

### 2. تشغيل البوابة المركزية لكامل المنظومة (المنفذ 3000)
```bash
npm start
```
افتح المتصفح على [http://localhost:3000](http://localhost:3000) للدخول إلى البوابة المركزية والتنقل بين كافة التطبيقات عبر الروابط المباشرة `/apps/<track>/<app>/`.

### 3. تشغيل أي برمجية بشكل مستقل عبر منفذها الخاص
يمكنك تشغيل كل برنامج كخادم مستقل ومنفصل تماماً:

```bash
# تشغيل DZ-Disk-Tree (بديل WizTree) على المنفذ 3001
npm run start:disk-tree

# تشغيل DZ-Archive (بديل WinRAR) على المنفذ 3002
npm run start:archive

# تشغيل DZ-Player (بديل VLC) على المنفذ 3003
npm run start:player

# تشغيل DZ-PDF Pro (بديل Adobe Acrobat) على المنفذ 3004
npm run start:pdf
```

## دليل المساهمة وتطوير المشاريع

نرحب بمساهمات المطورين، المهندسين، المصممين، المحاسبين، ورجال القانون الجزائريين:

1. قم بعمل **Fork** للمستودع وأنشئ فرعاً لميزتك (`git checkout -b feat/اسم-الميزة`).
2. التزم بالمعيار الهندسي لمشروع **HeyPuter** (جافاسكربت صافية، متجهات SVG، وصفر رموز تعبيرية).

4. تحقق من خلو الكود من الأخطاء عبر (`node --check <file>`).
5. أرسل طلب دمج تفصيلي (**Pull Request**).

للمزيد من الإرشادات، يرجى الاطلاع على [دليل المساهمة (CONTRIBUTING.md)](docs/CONTRIBUTING.md).
