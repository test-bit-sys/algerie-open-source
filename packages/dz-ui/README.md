# 📦 حزمة `dz-ui`
## Algerian Context UI Design System & Component Library

نظام تصميم ومكتبة مكونات مرئية عصرية وخفيفة الوزن، صُممت خصيصاً لتطبيقات الأعمال والإدارة الجزائرية:

---

### ✨ الخصائص المميزة
1. **ثنائية الاتجاه الأصيلة (Native Bi-Directional RTL / LTR):**
   * دعم كامل وفوري للتبديل بين العربية والفرنسية دون أي تشوه في الخطوط أو الهوامش أو الأزرار.
2. **خطوط عربية عصرية ومحسنة للشاشات الإدارية:**
   * اعتماد خطوط احترافية واضحة ومقروءة للمحاسبين والتجار، تمنع إجهاد العين أثناء العمل الطويل.
3. **مكونات مخصصة لبيئة الأعمال الجزائرية:**
   * حقول إدخال المبالغ بالدينار مع إظهار التفقيط الآلي المباشر أسفل الحقل.
   * حقول منسقة خصيصاً لأرقام NIF و NIS ورقم السجل التجاري والـ RIB.
   * قوالب جاهزة لعرض الجداول المحاسبية والفواتير.
   * دعم الوضع المظلم (Dark Mode) والوضع الفاتح (Light Mode).
